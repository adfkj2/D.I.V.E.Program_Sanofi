## 已交付

根目录 `启动续研.cmd` 调用本次进程范围的 PowerShell 引导，不改全局执行策略。引导检查 Python 3.11+ 与 Tk，优先使用独立环境或现有开发环境；缺少网页依赖时，新建 `.venv-workbench` 并安装固定版本的 runtime 依赖，不修改系统 Python 或开发环境。

原生启动窗口提供自动启动、打开浏览器、停止/重试、日志与数据文件夹入口；地址可复制。默认沿用根目录 `memory.db`。窗口关闭通过管道通知自己持有的服务子进程退出；不按端口或进程名结束其他应用。同一项目采用操作系统文件锁，重复双击核查实例后复用服务。端口被占用时由操作系统分配并保留可用套接字，避免先探测后绑定的竞争。

服务就绪后才打开浏览器；缺失/非法状态文件和其他 HTTP 服务不会被当作自己的工作台。固定本地证据模式，保留已配置的本地访问令牌。不自动加载或改写用户记录，不使用模型密钥。用户说明见[开始使用](../../开始使用.md)，包括桌面快捷方式和第一次在其他电脑安装 Python 的步骤。
