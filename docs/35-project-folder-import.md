# 创建时导入本地文件夹

创建项目现在可以从已有资料开始，初始化时保存“目前做到哪里、依据是什么、接下来做什么”。

## 使用方法

1. 点击左侧“创建项目”，选择“导入本地文件夹”。浏览器会要求选择文件夹；授权范围为这次选择的文件。
2. 等待本地分析完成。名称默认使用文件夹名称，仍可修改，也可以补充项目目标。
3. 阅读并修改“初始项目进度”，核对文件与行号；勾选要保留的待办。“下一步”也会保存为待办，不需要时可清空。
4. 保存项目。系统将资料快照、已确认的进度摘要、首次交接和选择的待办一起保存。下次打开，助手会从交接与相关记忆继续；修改名称和目标不影响导入资料。

分析过程中不能保存。可以移除文件夹后创建空项目，也可以取消并重新创建；移除后迟到的分析结果不会覆盖新的表单。失败时不会留下只有部分资料的项目；相同请求重试不会重复创建记录。

保存中的旧响应也不会关闭后来打开的新草稿。保存请求已经发出时，关闭界面不会撤销服务器已完成的创建，可在项目列表查看。大目录达到2000条路径上限时优先保留进度、README及可阅读文档，避免源码文件先占满名额。

## 分析范围

本轮采用本地文档整理，不调用模型、不执行项目代码，也不修改原文件夹。它提取 Markdown 勾选清单和明确的进度、阶段、阻塞与下一步描述，保留出处，供用户核对。文档中“已完成”仅表示文档的陈述，不能证明当前代码、测试或实验结果；不同时间的文档可能冲突。没有明确记录时会提示补充进度，不推测完成比例。

优先阅读进度/状态/TODO/路线图文档与 README，支持 UTF-8 的 Markdown、TXT、RST，以及 package.json、pyproject.toml、Cargo.toml、go.mod。代码文件只计入文件概况，PDF、Word、图片等内容暂不读取。隐藏文件、依赖与构建目录、常见密钥文件和检测到凭据内容的文档会被跳过；请在保存前核对分析来源。

一次最多保留 2000 个文件相对路径、阅读 24 份文本资料，每份前 12000 字符。源资料记忆正文保留前 6000 字符，来源摘录保留本次读取的完整选段。来源 SHA-256 针对该选段，不代表超出范围的完整原文件。达到上限或跳过文件会在“分析来源与范围”中说明。

导入结果是初始化时的快照，不保留对原文件夹的持续访问，不会随原文件变化自动刷新。导入的来源记忆属于所选项目，初始化元数据、交接和待办随 SQLite 完整备份保留。以后与模型对话时，选中的项目资料会按现有对话规则提供给所连接的模型。
