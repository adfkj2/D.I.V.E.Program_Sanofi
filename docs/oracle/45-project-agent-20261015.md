# R47：长期记忆项目 Agent

2026-10-15。用户确认将产品定位为“有长期记忆的个人项目 AI 助手”，以模型对话为主入口，首选 DeepSeek；要求与未来 benchmark 提分迭代解耦。

## 基线与实现

基线 R46 1215通过/9跳过，Oracle R40 451/500（90.2%）非官方开发自评。本轮不修改 Oracle reader、策略、judge、缓存、题集或费用账本。

实现独立 ChatModel / ProjectTools 协议，6步有界工具循环，当前项目上下文、记忆检索、来源核查、提案与引用编号校验。模型可提出待办新增/更新、记忆保存/更正、交接保存；用户确认后在同一事务执行并读回核验。持久化请求编号、提案状态和对话历史，支持重复请求去重、取消、过期检查、服务重启中断标记与完整备份恢复。HTTP与UI沿用本地令牌/同源边界，配置错误不回显密钥。模型设置位于主界面，网页密钥仅在服务进程内存，支持独立 DIVE_AGENT_* 环境变量。

具体接口、工具范围和解耦方向见[Agent 架构指南](../34-project-agent.md)。没有增加外部代码执行、联网搜索、自动仓库编辑、多人权限或云同步。

## 过程与修正

- 静态检查首次发现 messages 类型推断过窄及可选文本入参类型，补齐声明和默认值，不忽略诊断。
- 首批36项 Agent 测试通过。加入 HTTP 超大响应测试后，参数自动名称超过 Windows 环境变量32767字符限制，首次全量出现2项测试基础设施错误；改用短测试ID，原结果保留在本地 quality-first。
- 第二轮完整门禁通过：1267通过/9跳过，交付层行94.99%、分支91.28%，核心行91.99%、分支80.56%。该轮之后人工复核发现重复“记住相同事实”会强化既有记忆，但核验错误要求新会话编号，导致回滚。改为依据写入返回的记忆编号与实际字段核验，新增重复强化回归。
- 浏览器以本机 OpenAI 兼容 HTTP 协议替身执行，界面和回答明确标注“协议替身·非真实模型”。已验证连接配置、生成提案、确认执行3项操作、刷新后检索与引用、来源回看、390px窄屏无横向溢出、取消及连接失败输入保留。

## 边界

工程工具闭环已实现不等于真实模型理解可靠。引用校验只确认本轮读取过相应记忆；用户仍需审阅提案和依据。默认检索保持原配置，不移植Oracle成绩。下一步在用户自己的模型连接下做真实任务验收；benchmark可独立继续对照实验，不将UI演示、脚本模型或覆盖率视为答题准确率。
