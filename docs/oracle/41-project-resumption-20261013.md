## 问题与假设

当前首页主要展示字段卡片；主案例只有七条 A/B/C 合成记录；默认无密钥问答只返回检索片段，用户仍需自行把它们整理为工作简报。已通过工程检查并不代表这一流程有足够价值。

本轮假设：用本项目真实研发记录呈现“筛选成绩不等于全量成绩、结果不等于采纳、开发自评不等于官方成绩”的连续任务，并提供有来源、可带到下一次会话的简报，能更具体地展示记忆的作用。此假设不冒称已有用户研究或产品优势。

- 新增人工整理的仓库案例包，保存源文摘录、相对路径与哈希。运行时通过正常记录入口载入独立项目，不读取历史评测答案或依赖原始报告目录。

固定 Oracle 原数据、R40 提交、reader 策略与原始评估。不会继续根据原 500 题调参。无新增模型调用；历史累计费用仍为 ¥31.456754。规则认定、正式 judge、自然语言独立保留集和真实用户观察保持待完成。

## 验收方式

简报中的事实必须来自当前项目的有效明确记录；冲突不选一个值、提议不变成采纳；每条结论可打开原始来源。历史查询只使用当时可见记录；比较时间显式指定。交接文本可复制/下载，保留时间、来源与待确认项。未支持的自然语言问题明确说明范围，不编造回答。

新的任务验证只能证明记录处理和交互行为，不换算为 benchmark 提分、盲测或用户节省时间。完整结果及局限在实施后追加。
