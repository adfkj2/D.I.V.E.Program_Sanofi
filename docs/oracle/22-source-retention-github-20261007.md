## 公开方案核对

- [Mem0 memory-benchmarks](https://github.com/mem0ai/memory-benchmarks/tree/4b61c5d31b9c668a12b4f5e78064248a02c82d2b)：该提交报告云版94.8%、开源版91.0%。开源条件包含GPT-5抽取、作答及判分，默认数据为LongMemEval-S cleaned，不能与本项目Oracle及DeepSeek Flash自评直接对比。实现将相邻用户/助手消息分块，再检索、回答、判分。
- 其[回答提示](https://github.com/mem0ai/memory-benchmarks/blob/4b61c5d31b9c668a12b4f5e78064248a02c82d2b/benchmarks/longmemeval/prompts.py#L138)包含测试内容特定规则，例如吊灯算珠宝、咖啡店交换号码不算见面，以及把有日期且没有更新的计划假定为已完成。还有扩大模糊日期范围的指令。本项目不移植这些规则，不以其自报高分证明通用能力；也不使用外部逐题答案。
- [Hindsight](https://github.com/vectorize-io/hindsight/tree/8facc90ec086f1c6a6e5bb3b65b620bc4efbba2d)：保留事实、实体、时间与原始chunk关联；召回结合语义、词项、图、时间，经RRF和重排，支持受token预算限制的原文chunk。借鉴点是保留可追溯原句及其限定语。不是部署整个框架，未验证其宣称分数。
- [LongMemEval原仓库](https://github.com/xiaowu0162/LongMemEval)：Oracle只含证据会话；官方判分模型为GPT-4o，当前项目仍使用原DeepSeek Flash非官方judge。原仓库讨论turn/session粒度、检索key扩展与原文value，以及先抽取再推理。未切换数据、judge或加入评测标签。

读取的公开源码/文档原文保存在[research目录](../../eval/reports/oracle-source-retention-20261007/research/)，仅作为研究资料，不进入运行时。

## 单一候选及固定条件

在现有选择性叙事片段基础上，增加独立的人称陈述锚点：一般过去式事件、第一人称状态/习惯、my/our引出的带数值或名称的人物/物品属性。分句只用于定位；保存完整原句及有界邻句，保留打算、疑问、否定等原始语气，仍为OBSERVATION，不晋升为稳定事实。若问句之前有独立的陈述分句，可保留原文；单独问句、条件和虚构不产生新锚点。

仅用户来源、整条敏感内容过滤、8000字符消息上限、最多4个片段、每片段1800字符、前后各1句不变。写入不接触题目、参考答案或gold来源。原抽取路径不变；新选项默认关闭。Reader仍为R21的双阅读与答/拒分歧复核，含格式容错；top30、6000证据预算、文档补充、模型及judge不变。
