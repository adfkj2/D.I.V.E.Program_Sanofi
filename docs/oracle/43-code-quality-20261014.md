## 具体改动

1. 增加 `tools/check_quality.py`，集中配置于 `pyproject.toml`，CI 与本地使用同一入口。全 `src` 执行关键错误扫描；交付范围执行完整 Ruff 与格式检查；12 个交付模块执行包含未注解函数体的类型检查。全部测试采集分支覆盖，两个关键组分别要求行 90%、分支 80%。
2. 门禁保留命令日志、JUnit、完整覆盖率、跳过原因与归一化源码哈希；拒绝已有输出目录、未采集分支、缺失源文件、空分母、四舍五入凑门槛和检查中源码变化。默认清除继承的在线配置，PG 仍由独立作业运行。
3. 从 Web 提取无框架依赖的 `RequestMetrics`。统计与快照复制持锁，计时采用单调时钟，时延类型由不匹配的 counter 改为带 sum/count 的 summary。早期拒绝的 401/403 也进入固定 `unmatched` 统计并附无缓存响应头；不把原始路径、项目名、令牌放进标签。应用 lifespan 使用 finally 关闭数据库。
4. 增加 35 项行为与门禁检查，覆盖配置失败、显式在线组合但无网络调用、请求预算/失败保留、真实事务部分写入后的回滚、重启后连续失败与恢复、半开时间区间、追踪淘汰与跨项目来源边界、CLI 持久化闭环、并发指标与导入依赖方向。
5. 新增[五项评分证据页](../32-code-quality-evidence.md)与[走读和答辩材料](../33-code-walkthrough.md)，同步 README、验证页、运行说明及项目进度。准备材料不等于作者已经完成现场答辩。
