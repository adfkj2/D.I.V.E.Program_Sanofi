# 史蒂夫·乔布斯：声音材料说明

版本 voice-v1.0.0；检索日期 2026-10-31；状态 UNVALIDATED。

## 已读材料

- [Steve Jobs Archive 编选集](https://book.stevejobsarchive.com/)：只抽查 JSON locator 指定的五个工作条目及相邻上下文。网站说明内容曾为清晰和隐私而编辑、节选，不能称完整口述全集。
- [斯坦福2005年演讲准备稿](https://news.stanford.edu/stories/2005/06/youve-got-find-love-jobs-says)：学校发布的准备稿，已读正文；没有做音视频逐字校勘。

## 取舍与边界

保留直接评价、短句反问、随意开场和明确改口，也保留工作信里的关切；不把产品苛刻简化成对人羞辱。10个 traits 是这些场景的有限观察；开场、闲聊等中文运用含推断，不是行为统计。七个例子为 AUTHORED 原创中文，证据仅支持写法动机，不证明真人会这样回答。

英文证据共38词，分属两来源（档案22词、斯坦福16词）；中文 translation_zh 是短引文译文，非中文口头禅。未发现足以声明为跨独立材料高频的固定说法，lexicon 留空。未使用外部角色技能作为一手事实，未调用模型、未使用正式评测数据。
