## 本轮失败及修正

1. 初次新增测试的临时目录父目录不存在，10 项 setup 错误；建目录后 11 项通过，没有删除断言。
2. 首次 reader 比对失败仅因审计适配器漏附 `spec`，保存差异，补齐元数据后全 500 一致；不是修改模型结果。
3. 请求上限测试的假响应漏填必需 model 字段，引发预期的 fail-closed 中止；修正测试夹具。
4. 浏览器初查发现 favicon 404；增加本地 SVG 资源后全交互与控制台检查通过。截图关闭过渡动画以免截到半透明帧。
5. npm 默认缓存目录无写权限；改用仓库内临时缓存。格式工具不自动识别 SVG，改为只检查其支持的静态格式；SVG 通过真实浏览器载入。
6. 初次风格/类型检查发现 import 顺序、变量类型和 CLI 恢复分支返回形状问题；已修正并重查。
7. Docker 客户端存在但 daemon 不可用；没有把 PG 的环境跳过描述为后端验证成功。CI 单独启动 PG 服务。
8. 公开许可证初次网络读取超时、连接器不可用；经允许的公开网络读取后保存 LongMemEval MIT 声明。
