# 微信式聊天：当前设计

本次升级维持以下蓝白视觉，侧栏简化为聊天、我、设置；严格许可通过后增加虚拟空间。「我」以头像与真实资料为入口，已校验版本和草稿可并排查看；模型配置使用居中对话框；VS是唯一强化的视觉元素，周围保持简洁。进度条只使用后端完成计数，输入动效反映实际生成，尊重减少动态效果设置。最新桌面/手机复核见 `artifacts/upgrade-e2e/report.json`，旧版记录保留在下文。

2026-10-30，经用户确认的新设计替代下方初版：64px功能栏、280px人物/会话列表、全高聊天区；手机采用列表与单聊两屏，保留返回按钮和底部功能导航。人物资料默认收在抽屉中，输入框固定在聊天区底部。

使用浅灰白 `#F3F5F9`、白色 `#FFFFFF`、墨色 `#243247`、次级文字 `#718096`、主蓝 `#3F6EC6`、自己气泡 `#E3EDFD`。全站本机无衬线字体；消息16px、联系人15px，辅助信息至少10–11px。桌面头像44px，统一浅蓝背景手绘插画，UI只在加载失败时使用姓名后备头像。

首发15人按五领域分类，芒格、巴菲特、张雪峰固定置顶。历史、自定义人物和苏格拉底式角色兼容保留，因此旧空间可能显示多于15个联系人。预览人物和点击开场话题不会生成假会话；首次发送才创建。消息左右分布，AI角色和离线模式持续可见，私人记忆为每条独立批准。

复核后加强了主按钮与正文对比度，修正初稿辅助字号过小；15头像等比优化至256px，总体积约1.95MB，原图与生成记录保留。完整浏览器验收见 `artifacts/im-e2e/report.json`：六视图×1440/768/390/360px无横向溢出，27张成功截图，另保留早期失败与修复证据。

## 初版历史便笺（已被以上方案替代）

2026-10-30，以 SDD 第 10 节为视觉依据，使用 frontend-design 技能。

第一轮：纸色 `#F6F3EC`、纸白 `#FFFDF8`、墨 `#24352F`、青绿 `#416C5B`、雾蓝 `#E2E9E9`、灰 `#747A70`。标题用本机 Songti SC / STSong / SimSun 中文宋体，正文用 Microsoft YaHei / PingFang SC。本机字体不触发外部字体请求。桌面左侧书脊式导航，中央长阅读区，右侧真实来源边注；主文左对齐，每行控制在约 60 个汉字。移动端导航横向滚动，主内容单列，来源区折叠。

```text
书名与导航 │ 当前空间                    │ 来源边注
           │ 对话、三轨镜像或模拟时间线   │ 证据 / 不确定
本地模式   │ 输入与明确授权              │ 删除 / 更正
```

第二轮审查：暖纸和宋体是规范明确方向，保留。取消通用数据指标卡、数字人格准确率、渐变光晕和大面积装饰插画。只在首次真聊的空状态使用一对对话括号作识别点，其余页面以真实内容、时间和来源组织。三轨用相邻阅读栏而非排名卡；模拟以私人剧场双侧发言呈现，每条永久写出“AI 模拟”。未加载到的用户数据一律用空状态，不伪造聊天和证据。操作反馈依赖真实接口返回。

交互基线：可见键盘焦点、表单显式 label、错误 aria-live、所有异步写入禁用重复提交、删除和目标批准使用确认对话框、减少动态效果、窄屏无横向溢出。Mock 模型状态持续可见，不把演示回复宣传为真人或人格验证。

实测复核：生产构建和 TypeScript 检查通过。独立空测试库上的 Chromium 纵向路径覆盖真聊、来源更正、三轨版本、目标本人确认、模拟公开批准/逐条发言/反馈/暂停恢复、现实自报、下载导出与删除级联。六视图分别在 1440、768、360px 无横向溢出；已目视查看桌面镜像与模拟、移动端真聊与模拟截图。每条模拟的永久标记、来源和现实自报措辞清晰。完整结果见 `artifacts/e2e/report.json`。这些是交互与工程验证，不是人格效果证明。
