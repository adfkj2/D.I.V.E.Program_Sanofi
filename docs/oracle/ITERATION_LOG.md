## R21 · 2026-10-07 · 格式容错与失败记录修复（已完成）

**问题与假设。** 第二次阅读格式无效时，原组合会丢弃已通过校验的首轮结果。可以按统一运行时状态规则恢复首轮，避免机械格式错误造成额外损失。

**实现与边界。** `recover_invalid_secondary=True` 只在第二轮 `INVALID` 且首轮为有效 `ANSWER` 或 `ABSTAIN` 时启用；真实拒答按原分歧规则处理，超时、传输失败和双重无效不会被隐藏。保留阶段用量及来源信息，不按题目 ID、参考答案或对错路由。默认关闭。另将 runner 的最终失败清单改为从全部保存记录重建，修复续跑漏报；这是评测可靠性修复，不单独计算提分。
