## 已处理机制与剩余边界

- R37保留请求/计划句里的既有事实原句，避免用户事实未形成记忆；全量源码与证据仍可追溯。
- R38/R39区分“需要有引用的用户事实”和“基于事实的新建议”，修复把建议当历史回忆而要求非必要前提的误拒。
- R40只在有多个可见日期的当前状态/习惯问题中独立检查同属性更新，修复部分新状态被旧值覆盖的误答。
