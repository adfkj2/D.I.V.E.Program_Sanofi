# 人物 Agent 的公开资料查证

普通聊天与虚拟空间共用应用提供的公开查询服务，当前支持 DeepSeek、Kimi、智谱、博查及 Tavily。事实依据来自公开网页，人物的口吻、思考方式与互动习惯仍来自原表达档案。各境内接口及模型 Key 复用见[境内联网适配](DOMESTIC_WEB.md)。静态人物资料不会因为获得联网能力而变成当事人的真实发言，拟真效果仍需用户实际试聊验证。

## 配置与使用

在「设置 → 联网查询」选择来源，可复用已保存的对应官方模型连接，也可填写该服务 Key，选择系统安全存储或仅本次运行，点击「测试并保存」。测试本身会发起一次搜索，单独记录为 TEST；失败不替换已有配置。成功后显示保存方式，由用户关闭窗口。Key 不回读、不进入浏览器永久存储、数据库正文、通用幂等响应、日志或导出。系统凭据库不可用时可选择仅本次运行。

配置成功后按需查询，普通聊天与每场虚拟会话都有独立开关。打开历史、查看来源、额度追加和服务重启都不会开始新的查询。更改会话联网开关会停止本场未发布内容，避免旧设置下的结果继续发布。Key 移除或轮换不会删除历史已发布来源卡；相关私人证据撤回则清除依赖内容与缓存。

标题下的「正在查资料…」「正在核对资料…」「对方正在输入中…」对应实际运行阶段。来源默认收起，点击气泡下「查看依据」可查看原链接、机构/域名、适用年份、发布时间、查询时间及保留的短摘录。没有读取成功的网页标为「资料未读取」。来源入口不会在后台加载外站图片、脚本或网页。

## Agent 与事实边界

运行层识别受限的 SEARCH、REPLY、CLARIFY 动作。所有动作先校验，最终自然回复沿用既有分条协议、格式处理、完整输出恢复和发布队列；内部控制内容不进入气泡。仅应用能决定实际请求，角色资料和网页均不能新增工具、执行脚本、读取秘密或访问其他会话。

每次回应最多两轮检索、三次搜索、五个页面（读取失败也占页面名额），检索阶段累计最多45秒；来源包按完整段落或表格行收敛到约6000估算 token。应用只连接已适配供应商的固定官方 API，不直接抓取任意网站。目标 URL 只允许无凭据的公开 HTTP/HTTPS，拒绝本机、私网、链路本地、保留地址与非网页协议，并限制 DNS 等待及返回正文大小。

搜索只发送必要公开查询词、年份、区域及直接相关条件，不发送完整聊天、人物 Skill、本人画像、真实记忆或保留题答案。查询词仅在本次请求内存在，数据库保存请求哈希、状态及用量，不保存查询原文或网页全文。来源保存有界摘录和哈希，以便追溯。

同场、相同条件的已发布证据可在15分钟内复用；不同会话不共享私人查询状态。历史摘要携带来源与时间限制。未发布的来源、草稿和待发尾部不能提供给另一位 Agent，检索内容不自动成为用户真实记忆。

报考场景先核对招生年份、省份、科类/选科、分数、位次与批次；缺少条件则按人物口吻追问。优先使用省考试院、高校招生官网与原政策，区别年份、选科、投档线、专业线、计划和位次。新增具体录取数字需有已读取的匹配资料；查不到、来源冲突或尚未公布时保留不确定性，不以搜索标题补造数据。数字检查是针对报考的保守拦截，不是通用事实认证。

## 接口、持久化与用量

- `GET /api/v1/web/config`：只读配置、掩码与安全存储状态。
- `POST /api/v1/web/config/validate`：先测试再保存；输入 `api_key`（更新时可省略）、`remember_key`、`enabled`，返回 ADDED、UPDATED、TEST_FAILED 或 SAVE_FAILED。
- `DELETE /api/v1/web/config`：移除凭据，取消后续查询，保留历史来源。
- `PUT /api/v1/real-conversations/{id}/web` 与 `PUT /api/v1/virtual-sessions/{id}/web`：`{enabled:boolean}`。
- `GET /api/v1/research-runs/{id}/sources`：仅提供实际已发布且未撤回内容的来源。
- 普通消息和虚拟发言附加 `research_id`、`source_refs`；查询任务、调用与发布关系独立持久化，不向普通状态接口暴露未发正文。
- 虚拟会话默认20次外部请求；`POST /api/v1/virtual-sessions/{id}/budget` 支持 `add_web_requests`（单次0–20，保留幂等要求）。达到上限进入 `PAUSED_LIMIT/WEB_REQUEST_LIMIT`，追加不自动恢复。

规划、补充检索后的模型回应及截断重试均使用既有两个全局模型槽位并按实际 token 记账。联网有独立的两个并发槽位，记录搜索/读取次数及服务返回的 credits，未知费用显示未估算。取消后迟到的付费用量仍照实记录，结果不再发布。网络等待不持有数据库事务。

schema v6 增加消息来源元数据。升级前完整备份应用库、记忆库、私有评估库和头像；保留旧 ID、自定义人物、历史聊天、评估与门禁。旧运行会话在服务重启后暂停，由用户手动继续。嵌套数据库事务使用真实外层事务和保存点，来源与消息发布/撤回保持原子性。
