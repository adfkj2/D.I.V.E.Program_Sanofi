# PFE v0.1：可复现的合成评测框架

当前交付只验证评测管线能否运行。所有用户、证据、参考答案均为公开可提交的虚构测试数据；生成器是确定性 mock，实际外部请求和 API 费用均为 0。报告不能证明人格忠实度、目标一致性或现实成长，也不能激活 `DOMAIN_TESTED`。

## 运行与实际验证

在项目根目录执行：

```powershell
$env:PYTHONPATH = 'backend'
python -m wot.evaluation --output artifacts/evaluation/synthetic-report.json
python -m pytest tests/test_evaluation.py -q
```

2026-10-30 本机实际结果：`15 passed in 0.21s`；CLI 输出 `8/8 paired cases; external calls 0; cost CNY 0.00`。全局 Python 未安装 ruff，之后使用旧项目虚拟环境内的 ruff 对本模块和测试进行了检查。

## 数据与答案边界

模块是独立离线入口 `wot.evaluation`，不应被应用 API、Persona Builder 或 Simulation 导入。CLI 只读取固定的 `eval/public_synthetic/sample.json` 和 `eval/protocols/eval_protocol_v0.1.json`，没有任意数据文件参数，更没有私有答案路径参数。真实独立保留集尚未接入；`eval/private` 不应挂载到应用运行环境。

采用“同一个人的训练历史 → 新会话/新时间问题”的个体化设计，**没有声称训练人与保留测试人彼此独立**。每位用户的 train/dev/holdout 会话互不交叉，时间窗口严格递增；开发与保留问题进行规范化和近重复检查。训练材料还必须满足本人主体、真实来源及 `PFE_TRAINING` 用途授权。模拟、外部 Skill、模型推断和评测私有答案不能作为训练记录。

`GenerationRequest` 只包含公开题面、选项、授权的训练上下文、上下文引用与冻结生成配置；不包含 case 对象或 reference 字段。参考答案只交给离线 scorer。测试在每条真实请求里检查参考答案 canary 与跨用户资料，避免仅测试声明。

## 四个独立实验臂

| 实验臂 | 提供给同一个生成器的上下文 |
|---|---|
| B0 | 无个人资料 |
| B1 | 首次训练自述构成的冻结静态简介 |
| B2 | 普通词项重合检索，取 top-k 真实训练记录 |
| D | 按领域筛选、保留来源和时间的结构化训练证据 |

各实验臂实际构造不同请求，再分别调用同一个 mock provider。provider 不读取实验臂名称来决定答案，而从实际给到的上下文中选择最近的适用记录，或拒答。所有臂使用相同 provider/model/temperature/prompt version、最大上下文字符数和最大输出 token 配置；每次请求记录指纹和实际引用。mock 没有真实 token 计量，报告明确表示未测量，不能冒充生产模型用量。

**D 当前只是结构化上下文测试替身，不是生产 `DiveMemoryAdapter` 的真实检索性能实验。** 四臂用来证明表示、调用、计分和统计流程独立可运行。它们不构成真实模型或 D.I.V.E 的效果比较。

## 计分、缺失和统计

选择匹配使用冻结选项精确比较；核心理由按冻结短语 rubric 计算覆盖。主指标为两者均值，无理由 rubric 时只计选择。该规则是透明的合成 fixture 判分，不能代替盲态人工评价。语言风格与人际态度人评分保留为 `null`，避免编造分数；拒答按参考答案明确标记，不能靠全拒答获得普遍正确。

每个预期题目都必须运行四臂。失败、缺失和伪造引用保留在逐调用账本，错误日志不记录异常原文或敏感 prompt。报告同时保留期望分母、各臂完成/失败/缺失分母和被排除的题目 ID。配对估计只使用四臂都完成的相同题目；不得把被排除的失败隐藏为成功率。最强基线的选择规则预先写入协议：在共同完成集合上取 B0/B1/B2 的最高加权均分，平分按 B0、B1、B2 顺序决定。

先计算各题 D 减所选基线的配对差，再按“用户等权、用户内会话等权、会话内题目等权”聚合。固定随机种子 1729 进行两层 bootstrap：先抽用户，再在各抽中用户内抽会话，会话内全部题目一起保留。重复同一会话的一百道相同题不会被当成一百个人。少于两名用户时不生成置信区间；合成小样本区间也只验证实现，不能作总体推断。输入数据、协议和模型配置的 SHA-256 记录在报告中；运行前后校验冻结输入未变。

## 已完成与待完成

已验证：真实不同的四臂上下文、同生成器和预算、冻结哈希、按会话/时间拆分、参考答案与跨用户隔离、来源与用途拒绝、缺失/失败分母、伪造引用拒绝、配对差、用户/会话分层 bootstrap、种子复现和 CLI 报告。

尚未完成的研究工作：真实自愿参与者与告知同意、独立 Judge 数据权限进程、实际生产 DIVE 检索臂、persona-swap 负对照、多轮续写任务、独立盲态人评与评分者校准、试点后预注册的领域阈值、模型漂移失效政策。需要完成这些工作后，才可讨论分域实证结果；现有旧 LongMemEval 成绩不能挪作 PFE 证据。
