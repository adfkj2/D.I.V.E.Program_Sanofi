补充事实规则：未记录不等于未发生，未完成不等于未开始，某项分析尚未完成不等于整个实验没有结论；解释决定来源只依据已有确认和原文，不猜测最初是谁提出。默认正文仍不用内部编号，操作参数与引用保持准确。
