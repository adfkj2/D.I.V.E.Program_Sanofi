# 独立人物 Agent 与直接开放的虚拟空间

本轮将普通聊天和双人虚拟空间接入同一持久化角色运行层。虚拟空间直接开放；只有用户自己的分身需要对应 Skill 版本通过资料质量评估。

## 角色运行与完整发言

每个会话、参与者、人物版本有独立的`agent_instance`，保存上下文游标、有来源的历史摘要、待发消息、未完成检查点和调用轨迹。协调器只路由已发布消息并安排发言；角色各自组装原生user／assistant上下文。相同人物在不同会话中不会共享私聊、草稿或内部状态。

历史记忆采用本地抽取摘要和最近12条已发布消息，摘要保留来源消息ID，不新增模型调用，不改写原始历史。Skill是参考数据，不授予执行脚本、工具、联网或读取其他会话的权限。

每轮默认输出预算2048token。仅当供应商明确返回长度截断，才用4096、8192预算重生成尚未发布的整组消息，最多两次；不拼接残缺JSON或发布其前缀。正常完成、拒答、内容限制和网络／鉴权错误分别处理。空正文但有可靠用量的响应仍记账，再决定恢复。每次实际调用分别写入`agent_call`和原聊天／虚拟空间用量记录。

模型修复期间保持输入提示。无法完成时报告“本轮发言未完成”，保留可恢复状态；打开网页和服务重启不会触发自动付费调用。普通聊天继续支持插话清尾、稳定消息ID、失败重试及单次记忆授权。

## 开放空间与本人资料质量准入

侧栏和虚拟空间页面始终可访问。真实生成仍需有效模型连接、人物准入与本场分享授权。创建请求支持`start_immediately`，默认false兼容旧调用；新界面显式传true，一次确认即可开始。

「我」的默认评估是“本人Skill资料质量评估”：五项等权、综合至少80、每项至少70，来源、许可、权限和诚实检查全部通过，且必须为LIVE结果。它检验资料可用性，不证明真人拟真。

本人版本冻结原正文、本人介绍、真实授权来源及已批准目标；评估开始前由用户确认本人身份及分身使用授权。不伪造公开资料、MIT许可或空壳分数。新版草稿不会取消旧合格版本；头像、昵称、Key及生成模型变化不要求重新做资料质量评估。撤回版本所依赖的证据或目标则同步失效。

原严格本人校验保留为可选高级功能；旧报告和许可不转换为虚构的QUALITY成绩。旧SELF会话需要对应版本取得新质量准入后恢复。个人校验变化不停止没有依赖这些个人资料的纯人物会话。

新增`POST /api/v1/me/versions/{version_id}/assess`，请求为`{confirmed:true}`。评估任务继续复用进度、报告、取消、恢复接口；`QUALITY.subject_type`由服务端区分`SKILL_IMPORT`和`USER_SKILL`。`GET /me`提供`self_admission`和已准入版本，应用状态提供`virtual_access.enabled=true`。

## 额度、慢聊与干预

默认20条实际消息／30000总token；达到限制进入`PAUSED_LIMIT`，以`MESSAGE_LIMIT`、`TOKEN_LIMIT`、`BUDGET_PRECHECK`区分原因。估算用于调度，不当作已经消费的token；账本使用供应商实际用量。

`POST /api/v1/virtual-sessions/{id}/budget`接受`add_messages`与`add_tokens`，单次最多20条、30000token，并要求幂等标识。追加额度不会自动生成，点击继续后恢复原角色、参与者顺序和已付费待发位置。

组内1至4秒，人物交接12至25秒；本人分身每条草稿至少5秒。接管取消原尾部，手动文字保持原样。未发角色内容不通过公开接口提供给对方，只有本人分身当前可干预草稿单独展示。模拟文字和角色内部记忆不自动成为真实用户证据。

数据库升级前生成完整备份，版本更新为5。旧活动会话启动后暂停，由用户明确恢复。Windows／安卓打包、签名和Release发布继续暂停。
