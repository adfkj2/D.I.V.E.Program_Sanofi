日期：2026-10-31。交付范围为本地测试页面；Windows／安卓打包、签名和 Release 发布按用户要求暂停。

## 行为

十五位内置人物升级为 `wot-curated-v1.1.0`，每位具有具体判断规则、语言节奏和三组原创连续对话范例。它们是产品整理的表达示例，不作为人物原话引用。上游固定版本、原始 Skill、MIT 声明及来源核对范围保留，整理正文的哈希单独更新。

普通聊天与虚拟空间共用自然聊天提示：回应当前问题、依照角色思路表达，减少报告式结构和机械追问。台词不主动重复 AI 身份，直接问身份时简短如实回答。小标识留在标题，详细边界在人物资料；离线状态由界面展示。离线演示有三轮不同回复，不能用于声称真实模型表达已通过人工评价。

`dialogue.prepare_dialogue_reply()` 只在新模型回复保存前及新虚拟草稿暴露前运行一次。基于固定 `markdown-it-py==4.0.0` 的块／行内解析，转换标题、强调、列表、引用、表格、链接及围栏。代码与数学内容先按上下文保护，保留运算符、变量、数值、单位、网址和正常换行。明确的 Python 语句只用 AST 识别，不执行。表格保留多余列，避免标准渲染器丢弃非标准输入的值。

持久化文字同时供气泡、预览和后续公开对话使用。读取历史、失败重试返回已有回复、发布草稿均不重新处理。用户原文、手动接管文字、Skill、评估 JSON、本人保留答案及旧记录不经过该函数。虚拟调用的实际用量先入账，格式无有效内容时任务显示未完成。

配置改为「测试并添加／测试并保存」。服务端先测试临时草稿，通过后才保存；窗口区分测试失败、连接成功但保存失败、已添加和已更新。等待／失败保留掩码输入，成功展示「已保存 Key」或「仅本次运行有效」和更换入口，用户点击「开始聊天」关闭。重新打开仅展示安全状态。表单修改使旧结果失效；重复提交和迟到响应有保护。
