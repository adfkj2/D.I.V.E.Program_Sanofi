## 新策略与解耦

`deliberative-staged`是独立可选候选，默认策略保持。沿用来源编号协议与严格JSON/出处校验，由可注入的阶段执行配置指定模型、额度和恢复槽，领域层不构造供应商客户端。

| 阶段 | 模式 | 最大输出tokens |
| --- | --- | ---: |
| 搜证计划 | 普通模式 | 8192 |
| 答案合成 | 思考模式 | 16384 |
| 最终复核 | 思考模式 | 16384 |
| 共享恢复槽 | 普通模式，最多一次 | 8192 |

三个正常阶段均必需，总调用仍最多4次。格式错误、空回答与明确截断共用一个恢复槽；恢复只使用该阶段原本有权访问的材料和简短分类反馈，不回送截断文本或推理内容。即使截断文本恰好能解析，也不直接接受。内容过滤、异常结束状态、传输故障和未知总用量立即失败，不用草稿充当最终答案，也不自动重试。

传输层新增可选终止原因与推理token数；显式终态的null内容保留为空文本和已知总用量，不再丢失费用证据。缺少内容字段仍是响应结构错误。总用量只接受非负整数，拒绝将小数、字符串、负数或布尔值转换为已知费用。推理用量只是总输出的子项，不重复收费；不保存推理原文。缺少可选推理拆分不等于总费用未知。

每次调用记录实际阶段、配置、终态、用量和返回模型。阶段配置、思考强度、总调用上限和片段长度进入运行身份，防止更改这些参数后续跑混合旧输出。旧无阶段配置的策略不新增该身份字段。

这改变了模型搜证行为，不能称作语义等价的工程修复。普通模式可能漏搜证，恢复模式可能降低复杂推理质量，增加额度也可能提高成本和延迟。每题含恢复的理论输出上限49152，仅输出峰值费用可达¥0.393216，不能保证100或500题在整体预算内完成；逐请求预留与阶段费用上限必须继续强制执行。
