# 虚拟空间运行与隔离

`VirtualSpace` 属于本机服务。浏览器只读取状态和发起控制，关闭网页不会停止运行。服务调度线程每 200ms 检查可运行会话，按最近分配时间排序，最多两个工作线程，每场通过 `inflight` 防止重复生成。模型连接管理器另外在全应用范围限制最多两个实际请求。

开始前后端校验严格个人许可、许可模型、参与者及版本、必填话题、自动分享授权和限额。两侧不能选择同一版本。默认最多 20 条已发布发言或 30,000 总 token，无价格资料时显示“费用未估算”。执行前以请求 UTF-8 字节加余量保守预留预算，剩余不足时停止。实际调用用量独立提交，随后即使结果因暂停、删除或模型更改被丢弃，也不会撤销已发生的用量。

每个角色分别收到本人的冻结版本及已发布公共会话。只有本人分身读取已校验的本人 Skill；外部人物不读取这个 Skill。对话发言始终带“AI 模拟”、角色版本、模型指纹和连接记录。发布后根据字数安排 12–25 秒阅读间隔，下一次生成慢于间隔时继续等待，不以假回复补齐。

本人发言在发布前保留至少五秒。点击接管暂停发布；修改明确区分仅本轮、确认的真实更正、确认的理想方向。干预事件记录原稿 ID、所用分身版本、来源和本人确认状态。真实更正进入当前会话上下文及新版草稿，长期分身仍保留原已校验版本。纯人物对话及仅本轮反馈不会变成真实证据。

暂停、停止、依赖失效和重启均增加会话 epoch，清除未发布草稿。在途返回先记入实际用量，再检查 epoch、状态、许可和版本，过期结果不发布。排队等待全局请求名额的调用接受取消检查，不会在用户暂停后重新发起请求。服务重启把未完成运行统一暂停，必须手动继续。

删除或撤回依赖会同步停用会话、清除当前更正上下文及未发布草稿。真实证据或目标被撤回时，还会清理依赖的派生发言和干预文本；单纯删除人物会保留已发布历史。即使回调因崩溃未运行，发布前也逐条检查当前更正来源仍有效。

## 并发边界

调度及干预提交以短数据库事务完成；网络请求不持有服务或虚拟空间锁。真实记忆写入在虚拟空间锁外进行，返回后按预留 token、epoch 和草稿 ID 再核对，避免暂停期间复活草稿。删除回调仅使用数据库事务，不反向获取虚拟空间锁，避免与调度形成锁顺序冲突。

## 测试

`tests/test_virtual_upgrade.py` 使用隔离的真实记忆服务、内存假模型及仅限测试的假许可，覆盖：门禁和授权、同版本拒绝、五秒窗口、12–25 秒间隔、四会话公平运行和两并发、无浏览器后台运行、暂停在途并计费、20 条和 token 限额、错误后的手动恢复、重启暂停、三种干预、来源删除传播、模型更换、人物删除保留历史、外观同步、全部暂停及干预与删除的锁顺序。假许可不会写入正式产品许可表，也不用于验收人格真实性。
