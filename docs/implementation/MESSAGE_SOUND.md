# 人物消息提示音

普通聊天与虚拟空间的每条新发布消息都有独立的轻柔双音提示，连续发来多条时分别播放。音效由本机 Web Audio 合成，不请求外部音频资源。

默认开启，可在聊天顶部、虚拟会话顶部或「设置 → 消息提示音」开关。浏览器会在首次真实点击或键盘输入后允许播放；没有获得播放权限时，聊天继续正常工作。静音偏好只以一个布尔值保存在本浏览器中，不保存消息、私人草稿或密钥。

## 消息与历史

- 提示绑定会话和稳定消息ID，重复轮询、失败重试与重新打开历史不会重复响铃。
- 自己在普通聊天中发送的消息、已删除消息、输入状态与未发布的分身草稿不响铃。
- 普通聊天切到设置或个人页后，已请求的回复仍通过只读轮询更新并提示；虚拟空间共用应用快照及当前会话轮询，双方发言只提示一次。
- 运行中的后台网页也可播放。浏览器暂停音频、禁止播放或不支持音频时不积压提示，恢复后不会集中补播历史。
- 关闭声音、删除会话或退出页面时清除尚未播放的对应音效。声音功能不发起模型调用，不上传任何内容。
